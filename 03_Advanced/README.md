## Learning Objectives

After finishing this section you will be able to:

- Implement inheritance hierarchies and use polymorphism correctly.
- Write generic code using function and class templates.
- Handle runtime errors gracefully with exceptions.
- Use STL containers and algorithms fluently.
- Manage dynamic memory safely with smart pointers.
- Read and write files.
- Recognise and implement common design patterns.
