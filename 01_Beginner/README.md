## Learning Objectives

After finishing this section you will be able to:

- Write, compile, and run a simple C++ program.
- Declare variables of common types (`int`, `double`, `char`, `bool`, `string`).
- Use arithmetic and logical operators.
- Read input from the user and display output.
- Control program flow with `if/else` and `switch`.
- Repeat actions with `for`, `while`, and `do-while` loops.
- Break code into reusable functions.

---

## How to Compile

```bash
g++ -std=c++17 -Wall -o output 01_hello_world.cpp && ./output
```

Replace `01_hello_world.cpp` with any file you want to run.
