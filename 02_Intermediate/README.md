## Learning Objectives

After finishing this section you will be able to:

- Use advanced function features (default args, pass by reference).
- Work with arrays and `std::string`.
- Understand pointers, references, and dynamic memory allocation.
- Define `struct` and `class` types with constructors and destructors.
- Apply basic encapsulation with access specifiers.
