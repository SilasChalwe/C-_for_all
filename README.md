# C++ for All

> **A complete, beginner-to-advanced C++ learning repository — created and maintained by [Silas Chalwe](https://github.com/SilasChalwe).**

Whether you are writing your very first `Hello, World!` or diving deep into template meta-programming, this repository has something for you.
Start at `01_Beginner` and work your way through each folder — every section builds on the last.

---

## Repository Structure

| Folder | Level | Topics Covered |
|--------|-------|----------------|
| [01_Beginner](./01_Beginner/) | Beginner | Syntax, variables, data types, operators, I/O, loops, conditionals, basic functions |
| [02_Intermediate](./02_Intermediate/) | Intermediate | Functions, arrays, strings, pointers, references, dynamic memory, structs, OOP basics |
| [03_Advanced](./03_Advanced/) | Advanced | Advanced OOP, templates, exceptions, STL, smart pointers, file handling, design patterns |
| [04_Algorithms_and_Data_Structures](./04_Algorithms_and_Data_Structures/) | Algorithms | Sorting, searching, recursion, linked lists, stacks, queues, trees, graphs |
| [05_Projects](./05_Projects/) | Projects | Small-to-medium projects that combine multiple concepts |
| [06_Extras](./06_Extras/) | Extras | Tips, best practices, C++ standards, modern C++ (C++11–C++20) |

---

## How to Compile and Run Examples

All examples are standard C++ and can be compiled with any modern compiler.

```bash
# Using GCC / G++
g++ -std=c++17 -Wall -o program program.cpp && ./program

# Using Clang
clang++ -std=c++17 -Wall -o program program.cpp && ./program

# Using MSVC (Windows)
cl /std:c++17 /W4 program.cpp
```
