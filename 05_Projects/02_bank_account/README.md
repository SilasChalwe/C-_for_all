# Project 2 – Bank Account Management System

**Author:** Silas Chalwe

## Description
A console-based bank account manager that supports multiple accounts, deposits, withdrawals, transfers, and account summaries. Optionally saves data to a file.

## Concepts Used
- Classes and OOP (encapsulation, data hiding)
- `vector` and `map` for account storage
- File I/O for persistence
- Input validation and exception handling

## Requirements
- C++17 compiler

## How to Compile & Run
```bash
g++ -std=c++17 -Wall -o bank main.cpp && ./bank
```

## Example Usage
```
=== Bank Management System ===
1. Create account
2. Deposit
3. Withdraw
4. Transfer
5. View all accounts
0. Exit
```
