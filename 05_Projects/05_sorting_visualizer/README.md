# Project 5 – Console Sorting Visualizer

**Author:** Silas Chalwe

## Description
A console-based visualizer that shows sorting algorithms working in real time using ASCII bar charts.

## Concepts Used
- Templates
- Algorithm implementation (Bubble, Selection, Insertion)
- Console output and ANSI codes

## How to Compile & Run
```bash
g++ -std=c++17 -Wall -o visualizer main.cpp && ./visualizer
```
