# Project 4 – Text Adventure Game

**Author:** Silas Chalwe

## Description
A small text-based adventure game. Explore rooms, collect items, and defeat an enemy. Demonstrates OOP, maps, and STL containers.

## Concepts Used
- Classes (Player, Room, Item, Game)
- `unordered_map` for room navigation
- Vectors for inventory
- OOP encapsulation

## How to Compile & Run
```bash
g++ -std=c++17 -Wall -o adventure main.cpp && ./adventure
```
