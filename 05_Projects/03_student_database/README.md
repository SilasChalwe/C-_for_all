# Project 3 – Student Database (CRUD)

**Author:** Silas Chalwe

## Description
A full CRUD (Create, Read, Update, Delete) student record management system with file persistence.

## Concepts Used
- Structs and vectors
- File I/O (CSV persistence)
- Search and sort algorithms
- Input validation

## How to Compile & Run
```bash
g++ -std=c++17 -Wall -o student_db main.cpp && ./student_db
```
