# 05 – Projects 🟣

> **Goal:** Apply everything you have learned by building real, working C++ programs.

---

## Projects

| Project | Description | Concepts Used |
|---------|-------------|---------------|
| [01_calculator/](./01_calculator/) | Command-line calculator with basic operations | Functions, loops, switch |
| [02_bank_account/](./02_bank_account/) | Simple bank account management system | Classes, OOP, file handling |
| [03_student_database/](./03_student_database/) | CRUD student record system | Structs, vectors, file I/O |
| [04_text_adventure/](./04_text_adventure/) | Small text-based adventure game | Classes, maps, STL |
| [05_sorting_visualizer/](./05_sorting_visualizer/) | Console-based sorting visualizer | Algorithms, templates |

---

## Project Structure

Each project folder contains:

```
project_name/
├── README.md          ← description, requirements, example usage
└── main.cpp           ← complete source code
```

---

## How to Compile

```bash
# Example: Calculator project
cd 01_calculator
g++ -std=c++17 -Wall -o calculator main.cpp && ./calculator
```
